# Agent-W-Trader Architecture

## Vision
Agent-W-Trader is a local-first Agentic AI trading research and decision platform for Indian markets.

## Core Principles
- Local AI models (Ollama compatible)
- No mandatory paid AI API dependency
- Risk-first architecture
- Explainable decisions
- Paper trading before execution

## Modules

- Orchestrator Agent
- Market Research Agent
- Candle Intelligence Engine
- News Intelligence Engine
- Strategy Agent
- Risk Management Agent
- Tax & Cost Calculator
- Portfolio Memory Engine
- Multi-screen Trading Dashboard

## Market Knowledge Engine
The system will learn and analyze:
- Indian equity markets
- NSE indices
- Futures & Options concepts
- Candlestick patterns
- Price action
- Volume analysis
- Market structure
- Technical indicators
- Risk management
- Trading psychology
